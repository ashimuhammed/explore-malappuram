# Explore Malappuram (എന്റെ മലപ്പുറം) 🌴⛰️

A modern, high-performance web platform built with **Next.js (App Router)** and **Tailwind CSS**, devoted **100% exclusively** to the local tourist destinations, hill stations, rainforests, waterfalls, and cultural heritage sites of **Malappuram District, Kerala**.

---

## 🌟 Highlights & Exclusivity
- **Strictly Malappuram Focus**: Every single destination, itinerary, and culinary stop is located inside the borders of Malappuram district. No cross-district filler content.
- **15+ Curated Local Attractions**:
  - **Hills & Treks**: *Kodikuthimala (Mini Ooty)*, *Arimbra Hills (Meghamalhar viewpoint)*, *Chekkunnu Mala (Edavanna)*.
  - **Forests & Wildlife**: *Conolly's Plot & Teak Museum (Nilambur)*, *Nedumkayam Rainforest Reserve*, *Kadalundi-Vallikkunnu Community Reserve*, *Cherumb Eco Village*.
  - **Waterfalls**: *Adyanpara Waterfalls (Kurumbalangode)*, *Keralamkundu Basin Waterfall (Karuvarakundu)*.
  - **Beaches & Backwaters**: *Padinharekara Beach & River Nila Azhimukham*, *Biyyam Kayal Hanging Bridge*.
  - **Heritage & Culture**: *Kottakunnu Hill Park & Zamorin Fort*, *Thirunavaya Mamankam Battleground*, *Thunchan Parambu (Tirur)*, *Ponnani Grand Mosque & Port*, *Mamburam Maqam*.
- **7 Malappuram Taluks Covered**: Nilambur, Tirur, Ponnani, Perinthalmanna, Malappuram Town, Kondotty, and Karuvarakundu.
- **Curated Full-Day Itineraries**:
  1. *The Royal Teak & Rainforest Trail* (Nilambur corridor)
  2. *Nila River & Coastal Gateway* (Tirur, Thirunavaya, Biyyam Kayal & Ponnani)
  3. *Misty Heights & Malappuram Town Heart* (Kodikuthimala, Arimbra & Kottakunnu)
- **Interactive Multi-Stop Itinerary Planner**: Pick 2 to 5 Malappuram places and calculate a direct route with a single click to Google Maps directions.
- **Authentic Malabar Culinary Guide**: Malappuram Kuzhi Mandi, Ponnani Meen Mulakittathu, Thalassery/Malabar Dum Biriyani, Chattipathiri, Unnakaya, Neypathiri with Erachi roast, and Sulaimani tea.
- **Travel Essentials & Transit**:
  - Calicut International Airport (CCJ) located right at Karipur in Malappuram district.
  - Scenic Nilambur-Shoranur railway line guide.
  - DTPC Malappuram official contacts and emergency helplines.
- **Wishlist & Offline Saving**: Bookmark favorite places to view anytime, print your itinerary, or map all saved spots directly.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (tested on Node.js v22)
- npm or pnpm

### Running Locally
```bash
# 1. Install dependencies (if not already installed)
npm install

# 2. Run the development server
npm run dev

# 3. Open in your browser
# Visit http://localhost:3000
```

### Production Build
```bash
# Create optimized production bundle
npm run build

# Start production server
npm run start
```
